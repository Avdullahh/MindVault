# App Review Notes

MindVault uses passwordless authentication only. There is no email and password login screen, and there is no separate registration screen.

To review the app, you can sign in with your own Apple ID using Continue with Apple. This creates an account automatically on first use. You can also use Continue with Google with your own Google account, or enter any email address to receive a magic sign-in link.

AI features are opt-in only. They run only when the user explicitly triggers an AI action, so you will not see automatic AI behavior during review.

Settings includes an optional "New password" field. This sets a backup credential only and is not a sign-in method. Sign-in always goes through Apple, Google, or the magic-link email flow described above.
